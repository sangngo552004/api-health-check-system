Đổi mode

Chọn một mode bên dưới. Mỗi mode sẽ có cấu hình riêng để tránh nhầm lẫn.

OK

Endpoint luôn trả 200 OK. Dùng để hệ thống nhận diện service đang bình thường hoặc để resolve incident.

SLOW

Endpoint vẫn trả 200 nhưng phản hồi chậm. Dùng để test rule về thời gian phản hồi.

ERROR

Endpoint trả mã lỗi cố định như 500 hoặc 503. Dùng để mở incident nhanh và dễ kiểm soát.

FLAKY

Endpoint lúc lỗi lúc bình thường, xen kẽ qua từng lần gọi. Dùng để test tình huống chập chờn hoặc rule lỗi liên tiếp.
